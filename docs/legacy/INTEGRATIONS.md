# External Integrations Specification — BhagvadMood Journal

> **Document Version:** 1.0.0  
> **Project:** BhagvadMood Journal  

---

## 1. Active & Optional Integrations

1. **MySQL 8.0 Relational Database:** High-performance local persistence for users, entries, and reflections.
2. **Matplotlib & Tkinter Canvas:** Graphical chart plotting pipeline rendering vector mood trends directly into GUI frames.
3. **OpenAI API (Optional):** Contextual supportive reflections using `gpt-4o-mini` when API credentials are provided.
4. **NLTK & TextBlob NLP Libraries:** Lexical tokenization, Part-Of-Speech tagging, and sentiment polarities.
5. **TkCalendar:** Native calendar date picker integration for historical entry retrieval.
