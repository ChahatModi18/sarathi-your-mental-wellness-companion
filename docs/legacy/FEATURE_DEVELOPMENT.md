# Feature Development & Roadmap — BhagvadMood Journal

> **Document Version:** 1.0.0  
> **Project:** BhagvadMood Journal  

---

## 1. Implemented Features (v1.0.0)

- [x] **Private Journaling Workspace:** Rich multi-line text input with word counters and auto-save.
- [x] **Context-Aware Sentiment Classifier:** Negation-handling NLP engine calculating polarity and subjectivity.
- [x] **Vedic Scripture Guidance Engine:** Sanskrit Shloka suggestions mapped to emotional states.
- [x] **Harm Prevention & Crisis Detection:** Automated keyword scanner with instant helpline display.
- [x] **Interactive Matplotlib Visualizer:** Mood trend graphing across past 7 and 30 days.
- [x] **Dual Persistence Engine:** MySQL relational database storage with transparent SQLite fallback.

---

## 2. Upcoming Roadmap (v1.1 - v2.0)

- [ ] **Cross-Platform PWA/Web Companion:** Lightweight progressive web application companion for mobile reflection sync.
- [ ] **Audio Journaling & Speech-to-Text:** Whisper-powered local speech-to-text transcription.
- [ ] **End-to-End Database Encryption:** SQLCipher integration for hardware-bound local AES-256 encryption.
